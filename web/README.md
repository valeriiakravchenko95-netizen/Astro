# Страница расчёта

Всё считается в браузере посетителя: эфемериды, дома, аспекты,
достоинства. Сервера нет, и это не только про удобство — дата и место
рождения физически не покидают устройство, отправлять их некуда.

## Что здесь лежит

| Путь | Что это |
|------|---------|
| `index.html`, `style.css`, `app.js` | страница и её оформление |
| `astro/` | расчёт: время, углы, дома, аспекты, достоинства, фигуры |
| `astro/constants.js` | ряд нутации, разница шкал времени, скачки секунды |
| `data/ephemeris.bin` | таблицы положений, 1920–2035 |
| `data/cities.json` | города для поиска места |
| `content/interpretations.json` | тексты трактовок — правятся вручную |
| `content/transits.json` | тексты про события неба |
| `data/events.json` | календарь событий: станции, аспекты, ингрессии, лунации |
| `places.js`, `readings.js` | поиск места и подбор трактовок |

## Как это собрано

Данные и константы не пишутся руками, а выгружаются из Python-ядра:

```bash
python3 scripts/build_web_ephemeris.py   # таблицы положений
python3 scripts/build_web_constants.py   # нутация, шкалы времени
python3 scripts/build_web_cities.py      # города
python3 scripts/build_web_events.py      # календарь событий неба
```

Пересобирать нужно, только если поменялось ядро или захотелось другой
интервал дат.

## Проверка

Расчёт в браузере — это перенос, а не обёртка, поэтому он сверяется с
оригиналом на четырёхстах картах по обоим полушариям и по столетию:

```bash
python3 scripts/make_reference_charts.py   # эталоны из Python
node web/test/compare.mjs                  # сверка
```

Долготы расходятся не более чем на девять десятых угловой секунды, углы и
куспиды — на три десятых, а дома, аспекты, фигуры, достоинства и
диспозиторы совпадают полностью.

## Посмотреть локально

```bash
cd web && python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Публикация

Рабочий процесс `.github/workflows/pages.yml` публикует эту папку на
GitHub Pages при каждой правке в `main`. Включить это нужно один раз: в
настройках репозитория, раздел **Pages**, выбрать источником **GitHub
Actions**. Адрес получится вида
`https://<владелец>.github.io/<репозиторий>/`.

Свой домен привязывается там же, в разделе Pages: указать домен и
прописать у регистратора запись CNAME на `<владелец>.github.io`.

## Ограничения

**Даты с 1920 по 2035 год.** За пределами таблиц расчёт откажется
считать, а не соврёт. Интервал меняется ключами `--from` и `--to` у
сборщика таблиц.

**Часовые пояса до 1945 года** в браузере местами расходятся с полной
базой IANA: в новых версиях зоны, совпадающие после 1970 года, объединены
с соседними, и более ранняя история потеряна. Проверка всех шестисот зон
показала, что задеты 122 — почти все далеко от нас; из зон бывшего СССР
затронута одна Рига, и то на полминуты в 1925 году.

**Таблицы собраны на ядре DE421.** Если положить DE440 и пересобрать,
значения сдвинутся на миллисекунды дуги — для астрологии это ничто, но
байты файла изменятся.
