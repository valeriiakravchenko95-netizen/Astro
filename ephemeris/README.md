# Эфемериды

Сюда кладётся ядро JPL в формате SPK. Ядро ищется автоматически, в таком
порядке предпочтения:

| файл | интервал | размер |
|------|----------|--------|
| `de440s.bsp` | 1849–2150 | ~32 МБ |
| `de440.bsp` | 1550–2650 | ~114 МБ |
| `de441.bsp` | −13200…17191 | ~3 ГБ |
| `de421.bsp` | 1900–2050 | ~17 МБ |

Загрузить:

```bash
python3 scripts/fetch_ephemeris.py          # de440s.bsp
python3 scripts/fetch_ephemeris.py --full   # de440.bsp
```

Путь можно задать и вручную — переменной `ASTRO_EPHEMERIS` или ключом
`--ephemeris`.

`de440s.bsp` при 32 МБ кладётся в git как обычный файл. `de440.bsp` на
114 МБ превышает лимит GitHub на файл в 100 МБ, и для него нужен Git LFS.

Данные JPL распространяются без ограничений на использование.
